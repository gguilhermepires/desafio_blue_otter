# Product Overview

## Purpose

This is the "desafio_blue_otter" (Blue Otter Challenge) project. The repository is currently in initial setup phase and does not yet contain application code. The project is configured to use Claude Code's spec-driven development workflow for systematic feature development.

## Development Approach

Follow the spec-driven development methodology for all feature work:

1. **Requirements phase**: Create detailed requirements in EARS format before design
2. **Design phase**: Develop comprehensive design documents based on approved requirements
3. **Task planning phase**: Create actionable implementation plans with specific task breakdowns
4. **Implementation phase**: Execute tasks systematically based on the approved plan

Always obtain explicit user approval before moving between phases.

## Key Principles

- Iterative refinement: Requirements, design, and tasks should be reviewed and refined until user approves
- Ground truth establishment: User approval establishes "ground truth" at each phase before proceeding
- Systematic approach: Follow the workflow sequentially - do not skip phases or combine steps
- Documentation-first: Comprehensive documentation precedes implementation
